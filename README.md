# Personalized Humanizer

Analyze a user's writing style from submitted documents and generate a Markdown style guide that can be used to instruct AI models to mimic that style.

## Setup

### Prerequisites
- **Python 3.11 or 3.12** (Python 3.13 is **not** recommended because some dependencies like `spaCy` lack pre‑compiled wheels, causing build errors)
- **VS Code** with the Python extension (recommended)
- **Ollama** (optional, for local LLM synthesis) – install from [ollama.com](https://ollama.com)

### Step 1: Create and activate a virtual environment

Use **Python 3.11** (or 3.12) to avoid compilation issues.  
If you have multiple Python versions, find the correct launcher with `py -0p`.

Create the environment (example using Python 3.11):

py -3.11 -m venv .venv311

If that fails, use the full path from `py -0p`, for example:

C:\Users\ASUS\AppData\Roaming\uv\python\cpython-3.11.15-windows-x86_64-none\python.exe -m venv .venv311

Activate the environment:

.\.venv311\Scripts\Activate.ps1

### Step 2: Install required packages

Ensure `requirements.txt` contains the full list (with `spacy`, `scikit-learn`, `sentence-transformers`, etc.).

Run:

python -m pip install --upgrade pip

pip install -r requirements.txt

### Step 3: Download the spaCy language model

The medium English model is recommended (`en_core_web_md`). The usual command may fail with a 404 error, so use one of these alternatives:

- **Option A:**  
  python -m spacy download en_core_web_md-3.7.1

- **Option B:** Install directly from PyPI:  
  pip install en-core-web-md

- **Option C:** Download the wheel manually from [spaCy models releases](https://github.com/explosion/spacy-models/releases) and install with pip.

### Step 4: Download NLTK data

Some feature extraction scripts will require NLTK resources:

python -c "import nltk; nltk.download('punkt'); nltk.download('averaged_perceptron_tagger')"

### Step 5: Verify the installation

Run this single command to check that all packages, the spaCy model, and NLTK data are ready:

python -c "import importlib; mods=['docx','pdfplumber','markitdown','bs4','markdown','spacy','nltk','textstat','sklearn','sentence_transformers','pydantic','jinja2','ollama','dotenv']; [print(f'{m}: OK') if importlib.import_module(m) else None for m in mods]; import spacy; spacy.load('en_core_web_md'); print('spaCy model: OK'); import nltk; nltk.download('punkt', quiet=True); nltk.download('averaged_perceptron_tagger', quiet=True); print('NLTK data: OK')"

Expected output: a list of `OK` lines and no errors.

### Step 6: Place source documents

Copy your `.docx`, `.pdf`, or other supported files into the `data/raw/` folder.

### Step 7: Run ingestion

python scripts/ingest.py

Cleaned text will be saved to `data/clean/`.

## Pipeline

- **Ingestion** → Clean text  
- **Feature extraction** → `data/profiles/style_profile.json`  
- **Summary** → LLM prompt  
- **LLM synthesis** → `data/output/Personalized-Humanizer.md`

## Troubleshooting

- **`No module named spacy`**  
  You are probably using the wrong Python interpreter. Activate the virtual environment and ensure you use `python`, not `py`. If still missing, run `pip install -r requirements.txt`.

- **`python -m spacy download en_core_web_md` returns 404**  
  Use the versioned command: `python -m spacy download en_core_web_md-3.7.1` or `pip install en-core-web-md`.

- **`py` points to Python 3.13**  
  Inside the activated virtual environment, always use `python`. The Windows launcher may ignore the venv.

- **VS Code shows package refresh errors**  
  This is a VS Code extension issue and does not affect the actual Python environment. You can ignore it or restart VS Code.
