# Personalized Humanizer

Analyze a user's writing style from submitted documents and generate a comprehensive Markdown style guide that can be used to instruct AI models to mimic that style while avoiding AI‑detectable patterns.

The final guide combines:
- Narrative overview (optional, generated by local LLM)
- Precise stylometric metrics
- Few‑shot examples from the user's own writing
- Full anti‑AI writing rules (chunked, uncondensed)
- Usage prompt template with burstiness parameters

## Prerequisites

- **Python 3.11 or 3.12** (3.13 is not recommended due to missing wheels for some dependencies)
- **Ollama** (required for the LLM narrative step and for validation)
- **A local LLM pulled via Ollama** – by default the pipeline uses `deepseek-r1:8b` for narrative and `llama3.2:3b` for validation. You can change these in `config/settings.py`.
- Raw documents (`.docx`, `.pdf`, `.txt`) placed in `data/raw/`
- Optional: `anti_ai_skill_raw.md` in the project root for full anti‑AI rules

## One‑Command Setup & Run

From the project root, run:

```
python setup_orchestrator.py
```

This single command will:
1. Find a suitable Python 3.11/3.12 installation.
2. Create a virtual environment (`.venv311`).
3. Install all required packages from `requirements.txt`.
4. Download the spaCy language model and NLTK data.
5. Chunk the anti‑AI skill (if `anti_ai_skill_raw.md` exists).
6. Ask if you want to run the full pipeline immediately.

If you answer `y`, it will execute the complete pipeline and produce the final output in `data/output/Personalized-Humanizer-Complete.md`.

**This is the recommended way to set up and run the project.**

## Manual Setup (Alternative)

If you prefer to run commands manually, follow these steps:

1. Create and activate a virtual environment:
   ```
   py -3.11 -m venv .venv311
   .\.venv311\Scripts\Activate.ps1
   ```
2. Install dependencies:
   ```
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
3. Download spaCy model:
   ```
   python -m spacy download en_core_web_md-3.7.1
   ```
   (If that fails, use `pip install en-core-web-md`.)
4. Download NLTK data:
   ```
   python -c "import nltk; nltk.download('punkt'); nltk.download('averaged_perceptron_tagger')"
   ```
5. Chunk anti‑AI skill (optional but recommended):
   ```
   python scripts/chunk_anti_ai_skill.py
   ```

## Running the Pipeline

Place your source documents in `data/raw/`. Then, with the virtual environment active, run:

```
python scripts/run_pipeline.py
```

This executes:
- `ingest.py` – convert raw documents to clean text
- `extract_features.py` – compute stylometric profile
- `generate_profile_specific_anti_ai.py` – create profile‑specific anti‑AI rules
- `build_guide_from_template.py` – fill the deterministic style template
- `generate_few_shot_prompt.py` – select representative examples
- `summarize.py` – build LLM prompt
- `generate_guide.py` – generate narrative style guide (requires Ollama)
- `merge_guides.py` – combine all parts into final output

Final output: `data/output/Personalized-Humanizer-Complete.md`

## Using the Final Guide

1. Copy the entire content of `Personalized-Humanizer-Complete.md` and paste it as the **system prompt** in a flagship model (e.g., ChatGPT, Claude, Gemini).
2. Use the provided **Usage Prompt Template** at the bottom of the file as the user prompt, replacing `[Insert topic or assignment question here]` with your assignment.

The system prompt contains the style profile, few‑shot examples, anti‑AI rules, and priority hierarchy. The user prompt only needs the task and output format.

## Validation (Optional)

To test the style guide, first ensure:
- **Ollama is running** (`ollama serve` or the desktop app).
- The required local models are pulled (`ollama pull deepseek-r1:8b` and `ollama pull llama3.2:3b`, or whatever you configured in `settings.py`).

Then run:

```
python scripts/validate.py
```

This generates a sample paragraph using the guide, extracts features, and compares them to the original profile. Results are saved in `data/output/validation_report.txt` and `validation_sample.txt`.

## Troubleshooting

- **`No module named spacy`** – Activate the virtual environment and use `python`, not `py`.
- **`python -m spacy download en_core_web_md` 404** – Use `python -m spacy download en_core_web_md-3.7.1` or `pip install en-core-web-md`.
- **Empty validation sample** – Increase `num_predict` in `validate.py` or `OLLAMA_CONTEXT_SIZE` in `settings.py`.
- **VS Code package refresh errors** – Ignore or restart VS Code.
